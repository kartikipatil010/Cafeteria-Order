## Cafeteria Order Data – Quick Analysis & Forecasting

## 📌 Project Overview

This project analyzes cafeteria order data to understand customer ordering patterns, identify peak business hours, compare branch performance, and forecast the expected number of orders for the next 7 days.

The project was developed as part of the **Cafeteria Order Data – Quick Analysis & Forecast Challenge** for an internship evaluation.

---

## 🎯 Objectives

The main objectives of this project are:

- Import and clean cafeteria order data
- Perform Exploratory Data Analysis (EDA)
- Identify important ordering patterns
- Analyze peak order hours
- Compare branch-level performance
- Identify high-transaction product categories
- Forecast orders for the next 7 days
- Generate useful business recommendations

## 📊 Exploratory Data Analysis

The analysis focuses on:

### 1. Peak Ordering Hours

Order activity was analyzed across different time periods to identify high-traffic hours.

Reported peak periods:

- **12:00 PM – 2:00 PM**
- **5:00 PM – 7:00 PM**

These periods can help cafeteria management plan staffing and inventory.

---

### 2. Product Category Analysis

The analysis indicates that:

- **Beverages**
- **Snacks**

together contribute more than **65% of overall daily transaction counts**.

This indicates that these categories are important for cafeteria operations and inventory planning.
